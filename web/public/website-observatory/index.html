Solid connections represent recorded browser request initiators. Dashed connections only identify the page in which requests occurred. Neither reveals server-to-server traffic. Bytes are completed response-body transfer bytes; unknown sizes remain unknown. Latency includes browser queueing and transport, not pure server processing. LCP is observed during the capture window, not a real-user percentile.

Evidence schema v1 keeps synthetic browser runs separate from future application traces, edge telemetry and real-user measurements. No request/response bodies, cookies, authorization headers, query strings, URL paths or visitor identifiers are retained. Reports are hosted privately by OrgPortal and retained for 30 days.
