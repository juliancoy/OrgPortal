# Public submission source

`orgportal/` is the draft 1.1.0 public package, preserving the existing plugin
identity and leaving the private development installation unchanged.

It is **not submission-ready**. Follow the
[release checklist](../docs/deployment/CHATGPT_PUBLIC_RELEASE.md) for outstanding
publisher, policy/support URLs, countries, commerce, reviewer access and demo
evidence. Review cases are authored, not recorded as passed.

After completing those items, ZIP only the orgportal directory and its assets.
Do not include credentials, private app bindings or dependency directories.
