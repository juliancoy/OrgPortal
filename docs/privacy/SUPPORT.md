# OrgPortal support

OrgPortal is published by Julian Coy. Email **julian@codecollective.us** for
help connecting ChatGPT, account questions, security reports, privacy questions
or requests to delete your data. Do not include passwords, access tokens,
private tool results or identity documents in your initial message.

For connection problems, include the approximate time, device, and the visible
error message with sensitive information removed. For a deletion request,
identify your account and whether the request concerns one organization or the
whole shared account. We will verify control before destructive changes.

OrgPortal is currently FOSS with no in-app purchases. Support is handled by the
maintainer; there is no paid support or uptime guarantee. Privacy requests have
a target acknowledgement within 7 days and completion within 30 days after
verification. We explain delays and any retained records.

See the [privacy and retention policy](RETENTION_AND_DELETION.md) and
[integration terms](TERMS.md). Public directory installation is pending review
and publication; a running MCP endpoint is not a public plugin listing.
